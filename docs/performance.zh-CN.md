# FPGA 性能实测

[English](performance.md)

原生编码器使用 VU13P 类 FPGA、一个 Rocket RV64 CPU 和一致性 DDR DMA 测量，CPU 与加速器均为 50 MHz。不分发具体开发板配置与下载文件。源码级数字适配层另行提供；这些数据不能代替重新适配系统的验证。

## 测量方法

预定三轮，每轮 32 个样例，各执行一次单任务和一次同图重复 32 任务批处理，共完成 3,168 个任务。每个完整输出文件及 DMA 补零均与固定的 libjxl 0.11.2 快速无损编码原件比对。样例覆盖 1–4 通道、八种尺寸至 256×256、每通道 8 位。全部逐样例数据见 [measurements.json](../evidence/measurements.json)，全部任务数字时间戳见 [task-cycles.json](../evidence/task-cycles.json)，输入和参考文件见 [fixtures.json](../tests/fixtures/fixtures.json)。

CPU 周期窗口从缓冲区准备完成后开始，包含命令提交至全部结果回收，不含输入准备、输出比对、串口输出及可执行文件加载。硬件延迟为 `(retired − accepted) / 50 MHz`，包含 DMA 与排队等待；首次输出为 `(first_write − accepted) / 50 MHz`。批处理吞吐用原始输入字节数除以 CPU 窗口，MB 为 1,000,000 字节。硬件时间戳与 CPU 提交/回收不是同一计时窗口。

前缀备忘缓存没有主动清空。一个批次重复同图，因此不是冷缓存或不同内容的批处理结果。没有软件编码器 CPU 基线，也没有实测加速比。

## 256×256 结果

数值取三轮中位数。批处理吞吐包含全部 32 个任务，不是取最快单任务。

| 通道数 | 输入字节 | 文件字节 | 硬件单任务（µs） | CPU 单任务（µs） | 批处理输入（MB/s） | 批处理像素（MPixel/s） |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 1 | 65,536 | 72,968 | 403.32 | 420.22 | 249.25 | 249.25 |
| 2 | 131,072 | 146,129 | 584.58 | 602.98 | 291.06 | 145.53 |
| 3 | 196,608 | 221,385 | 787.30 | 806.06 | 291.32 | 97.11 |
| 4 | 262,144 | 294,079 | 982.76 | 1,002.10 | 293.15 | 73.29 |

RGB 批吞吐范围为 291.27–291.54 MB/s，四通道为 292.97–293.21 MB/s。全部样例混合加权中位数为 259.63 MB/s，按总字节/总批时间计算，而非吞吐率算术平均。小图对固定开销敏感；数据保留全部三轮，包括样例 3 的波动。

这些合成样例的文件可能大于输入。此表不代表自然图像压缩率、应用端到端性能或通用 JPEG XL 性能。限制见[验证](verification.zh-CN.md)。
