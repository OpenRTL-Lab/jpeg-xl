# 验证与边界

[English](verification.md)

实际可执行步骤见[仿真](simulation.zh-CN.md)、[Chipyard集成](chipyard.zh-CN.md)与[驱动开发](driver.zh-CN.md)，先读[阶段路线图](reproduce.zh-CN.md)。命令明确区分组件RTL、适配器、数字系统生成、ELF构建和实际设备执行。

## 已验证实现

所附原生编码器在 FPGA 实现前通过了 136 项 RTL 仿真和 1,056 次 CPU 参考编码。测试包含组件、完整原生文件、反压、复位/取消/错误、算术行对照及故意错误负向测试。参考观察器调用真正的上游快速无损实现，不是另写一套编码器模型。分发的 32 对样例保留完整原始像素与编码文件，不只保留文件头或摘要。

后续裸机 FPGA 三轮性能测试完成 3,168 个任务，逐字节检查完整文件及补零。这是有限向量证据，不是所有输入的数学证明。此次发布准备不重跑历史多小时矩阵。当前分发检查与命令见[构建](build.zh-CN.md)；宿主检查成功不等于 RTL 或 FPGA 通过。

## 复现教程配套检查

新增公开单 Rocket 示例已对固定上游 Chipyard 源码完成编译：CSR/DMA 的 Verilator 测试、配置检查、FIRRTL/设备树生成、firtool 降低及 612 文件的组合 RTL 清单均通过。生成 DTS 含一个 CPU、4GiB 内存和编码器中断号 2。RV64 轮询示例与 benchmark ELF 交叉编译通过，并核过 ELF64/RISC-V 及 `_start`、`main`、`jxl_trap`；轮询示例另有 7 项宿主假寄存器协议测试通过。复用了公开依赖下载缓存，没有复制私有已编译 SoC 产物。

这些检查未在新增数字 SoC 中执行 ELF，也未构建整个 SoC 仿真器、bitstream 或 Linux 驱动。实际执行前须移植仿真分支固定 PLIC 常量。公开 TL-UL 测试现跳过不存在的 BCE 通道；这是测试环境修正，不改产品 RTL。

公开夹具重排及新发射原生测试环境也已生成 64 个完全匹配的 RTL 输出文件。运行期 ROM 负控直接使用这份已通过的同一个二进制，保留正常结果不重跑；实际命中 `FAST_NATIVE_OFFICIAL_BYTES`，二进制 SHA-256 不变。故障入口的 16 个场景 / 20 个任务结果全部通过，故意错误测试命中 `FAST_NATIVE_FAULT_STATUS`。宿主测试另检查无关负向错误必须拒绝、参考文件必须恢复。这是新复现入口的定向检查，不是重跑历史全部 136 项。

## 实现证据

受测实现综合 Setup WNS 为 +1.193 ns，失败 Setup 端点为零。代表性逻辑深度总体中，超过 20 级为 5,568 / 1,969,649（0.283%），剩余长路径均属于共享基线而非编码器。这个统计包含零级条目、排除单独报告的恢复组，不是所有数学路径的穷举。

布线及局部 DDR 偏斜修复后，Setup / Hold / 脉宽最差裕量为 +0.131 / +0.010 / +0.039 ns。1,700,070 条可布线网络全部布通，布线错误为零，默认 DRC 错误和关键违例均为零。这些是受测实现的观察结果，不代表本仓提供了新的整板构建。基线仍有输入/输出延迟缺项与 JTAG 非专用时钟例外，不能称为完整接口或 PVT 签核。

## 支持范围与排除项

已验证路径为每通道 8 位、无损、单组、宽高各 1–256、1–4 通道，采用固定快速无损参考配置。`src/main/scala/openimage/jpegxl/` 下有界编码器/解码器具有独立实验接口，不继承原生编码器验证资格。

不声明通用 JPEG XL 解码、有损、HDR、动画、多组、更大尺寸、Linux 驱动、以太网应用传输、板级中断或长期稳定性。FPGA 测试使用轮询。通用平台混入接口供移植，并非本次新验证的完整 SoC。不分发厂商原语实现、开发板文件和下载工具。

## 完整性检查

`SOURCE_MANIFEST.json` 记录分发源码与生成正文摘要。`PUBLIC_FILES.json` 索引除自身外的全部分发文件；它是完整性索引，不是密码学签名。检查器拒绝载荷缺失、多余、改动、错误相对链接和常见敏感字面量；不能证明不存在任何秘密或第三方权利问题，公开前仍须人工审查源码与许可。当前仓库保持私有待审阅。
